# Friendslop 研討會論文研究紀錄

這個 Repository 用來保存 Friendslop 研討會論文的研究決策、文獻筆記、遊戲分析、實驗設計、證據索引、章節規劃與口試材料。

目前研究方向：以 LFCG 比較 Hurezeanu 等（2026）提到的四款 Friendslop 案例——`Lethal Company`、`Content Warning`、`R.E.P.O.`、`PEAK`——整理合作設計上的共通點、差異與例外。研究目前不替 Friendslop 下正式定義，也不直接回答玩家為什麼使用這個名稱。

## 目前狀態

- 階段：研究設計與前三章準備
- 投稿目標：下一屆臺北數位圖像國際學術研討會；正式簡章尚待公告
- 指導會談：2026-08-18 已完成第一次研究方法討論，老師未指出重大方向問題
- 目前最重要的工作：把「設計差異是否真的增加玩家互賴」的測試方法寫得更具體
- 前三章交付：老師希望提早收到；研究者目前以 2026 年 10 月為工作目標
- 口試方向：以影片和實際分析為主，第一章簡短，重點放在第二、第三章與已完成的研究工作

## 使用原則

1. 重要主張都要能回查到文獻、官方資料、遊戲版本、測試情境、錄影或會談紀錄。
2. 觀察結果、合理推論、待驗證假設和老師已確認事項要分開寫。
3. 原始影片、受試者姓名、同意書與任何可識別個資不得放進公開 Repository。
4. 原始資料不改寫；修正以新增版本或處理後資料進行，並保留來源檔名與雜湊值。
5. 沒有實際完成的測試，不得寫成已驗證結果。

## Repository 導覽

- `project/`：目前研究狀態、決策紀錄、時程與名詞
- `meetings/`：老師會談與其他研究會議紀錄
- `literature/`：來源清單與逐篇筆記
- `research_design/`：案例選擇、LFCG 分析方法、玩家互賴實驗
- `data/`：資料保存規則、紀錄表模板與各遊戲分析入口
- `writing/`：章節規劃、主張—證據對照表
- `presentation/`：口試與影片播放規劃
