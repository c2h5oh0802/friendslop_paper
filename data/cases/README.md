# 四案例工作區

每款遊戲使用獨立資料夾，保存版本範圍、實機紀錄、LFCG 分析與證據入口。

## 案例

- `CASE-LC/`：Lethal Company
- `CASE-CW/`：Content Warning
- `CASE-REPO/`：R.E.P.O.
- `CASE-PEAK/`：PEAK

## 每款必須完成

- [ ] 固定版本、平台、模式、隊伍人數與設定。
- [ ] 建立實機錄影與影片索引。
- [ ] 完成四個 LFCG 面向，不只填候選項目。
- [ ] 每個重要判定附時間碼或可回查來源。
- [ ] 記錄反例與可繞過方式。
- [ ] 分開記觀察、推論與假設。
- [ ] 至少抽查部分判定。

完成的分析 CSV 建議放在 `data/processed/cases/`，檔名使用：

```text
CASE-PEAK_lfcg-coding_v01.csv
```

原始錄影不放 GitHub。
