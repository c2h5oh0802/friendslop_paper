# 處理後資料

這裡只放已去識別、可供研究回查的小型文字資料，例如：

- 四案例 LFCG 編碼表。
- 影片互賴事件表。
- 每隊每條件的彙整結果。
- 論文圖表使用的分析資料。

提交前檢查：

- [ ] 沒有姓名、遊戲帳號、聯絡方式或匿名 ID 對照。
- [ ] 自由文字沒有可辨識內容。
- [ ] 每列能回查 `session_id`、`recording_id` 或 `evidence_id`。
- [ ] 原始資料位置與雜湊值已登記，但私有路徑未直接公開。
- [ ] 排除的場次仍留在場次總表並記原因。
- [ ] 處理腳本或人工處理步驟已有版本紀錄。

資料尚未取得前，此目錄只保留說明文件。
