# 文獻資料

本資料夾保存來源清單、逐篇閱讀筆記與文獻能支撐的主張。正式寫入論文前，不能只靠摘要、搜尋片段或先前討論記憶。

## 工作流程

1. 先在 `sources.csv` 建立來源 ID。
2. 取得原文後，建立 `notes/LIT-XXX_*.md`。
3. 記錄實際讀到的頁碼、原意、限制與本文用途。
4. 把可用主張加入 `writing/claim_evidence_map.csv`。
5. 正式寫作時以來源 ID 和頁碼回查，不從記憶補引用。

## 閱讀狀態

- `not_acquired`：尚未取得全文。
- `acquired_not_read`：已取得但未完整閱讀。
- `partially_read`：只讀過部分章節或段落。
- `fully_read`：已完整閱讀。
- `verified_for_claim`：已逐頁確認要支撐的特定主張。

## 證據原則

- 作者、年份、篇名、頁碼與研究結果不得猜測。
- 二手資料只能用來找原始來源，不能自動取代原文。
- 學長姐論文可參考結構，但不當成核心學術事實來源。
- 未確認頁碼時，只能標成待補，不放直接引文。
- 若來源只支持「案例曾被提到」，不能擴大成「案例代表整個類型」。
