# 會談紀錄

每次與老師討論後，建立一份 `YYYY-MM-DD_advisor_meeting.md`。不要只記「老師說可以」或「要再深入」，要保留可執行的意思。

每份紀錄至少包含：

- 會談目標
- 研究者帶去的版本或材料
- 老師明確說的內容
- 研究者對回饋的解讀
- 已確認、仍待確認與被排除的事項
- 對論文或研究設計的影響
- 下一次最小交付

## 資訊標記

- `老師明確意見`：使用者能確認是老師直接說的。
- `研究者解讀`：根據老師回饋整理出的意思，可能需要下次確認。
- `工作安排`：研究者自己決定的時程或做法。
- `模型建議`：由輔助工具提出，不得寫成老師要求。

錄音或逐字稿若含個資，不放在公開 Repository。只在紀錄中寫私有儲存位置、檔名與雜湊值。
