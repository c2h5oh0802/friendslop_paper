# 研究工作路線

這份路線以 2026 年 10 月交付前三章給老師為目前工作目標。十月不是正式截止日；若口試日期或研討會簡章公布，需重新排程。

## 2026-08-18 至 2026-08-31｜固定研究問題與記錄方式

目標：讓後續資料都能使用同一套欄位保存。

- [ ] 回到 LFCG 原文核對四個面向、所有分類名稱與定義。
- [ ] 完成四案例分析表的欄位與判定規則。
- [ ] 整理目前文獻來源，補上完整出版資訊與可回查頁碼。
- [ ] 從四個候選變化中選出一個最適合做先導測試的項目。
- [ ] 完成基準條件、變化條件、主要指標與影片事件編碼規則。
- [ ] 確認口試日期、時間、前三章格式與校內研究倫理需求。

完成條件：另一個人只看研究設計文件，也能知道要觀察什麼、怎麼記、什麼不能主張。

## 2026-09-01 至 2026-09-15｜完成兩個案例的完整試做

優先案例：PEAK 與另一款資料較完整的遊戲。

- [ ] 固定遊戲版本、模式、隊伍人數與設定。
- [ ] 依 LFCG 完整分析，不只找目前想到的候選特徵。
- [ ] 每項重要判定附來源、截圖或錄影時間碼。
- [ ] 記錄反例、例外與無法判定欄位。
- [ ] 讓第二人抽查一小部分判定，確認欄位是否容易誤解。

完成條件：同一張表能用於第二款遊戲，不需為了符合預期結果改欄位。

## 2026-09-16 至 2026-09-30｜補完四案例與先導測試

- [ ] 完成其餘兩款的分析。
- [ ] 建立四案例總比較表。
- [ ] 選出最有證據的二至三項共同或差異設計。
- [ ] 若原型與招募條件允許，進行少量先導測試。
- [ ] 檢查影片事件是否能被一致辨認。
- [ ] 不把先導測試寫成正式效果證明。

完成條件：能清楚說出哪些是案例觀察、哪些是實驗假設、哪些仍沒有證據。

## 2026-10｜交付前三章工作稿

建議交付內容：

1. 第一章：研究背景、問題、目的、範圍與限制。
2. 第二章：Friendslop 相關討論、LFCG 與玩家互賴相關文獻。
3. 第三章：案例選擇、資料蒐集、LFCG 分析流程、實驗或預定實驗方法、資料管理。
4. 附件：四案例分析表、影片索引、先導測試結果或測試計畫。

交付前檢查：

- [ ] 題目、研究問題、方法和可主張結果一致。
- [ ] 重要主張都能連到來源 ID、證據 ID 或影片 ID。
- [ ] 未讀全文的文獻沒有被寫成已確認。
- [ ] 「互賴增加」沒有被寫成「更好玩」。
- [ ] 老師已確認事項沒有被改成模型或研究者自己的說法。

## 口試前｜影片與實際內容優先

- [ ] 影片依研究問題剪，不依遊戲宣傳感剪。
- [ ] 每段影片開始前顯示遊戲／版本／條件／要觀察的現象。
- [ ] 第一章只保留理解研究問題所需內容。
- [ ] 主要時間放在第二、第三章的框架、方法、分析結果與實際作品。
- [ ] 若有實驗，明確標示先導或正式研究。
- [ ] 若沒有實驗，提出可執行的設計與目前缺少的條件。

## 口試後至投稿前｜視證據決定論文版本

可能的兩條路：

### 路線 A：案例分析為主

四案例 LFCG 比較完整，實驗只作後續研究。適合實驗來不及或原型無法隔離單一變化時。

### 路線 B：案例分析加受控實驗

四案例先提出變化假設，再用原型測試一項變化是否增加互賴。適合已有穩定原型、招募與研究倫理條件時。

最後採哪條路，以實際完成的證據為準，不為了看起來完整而把未完成測試寫成結果。
