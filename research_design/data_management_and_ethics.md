# 資料管理與研究倫理工作稿

狀態：內部規劃。校內正式研究倫理、審查與保存規定尚未查證，本文件不能取代官方要求。

## 何時會涉及人類參與者

只分析四款遊戲規則、官方資料與研究者自己的操作時，不一定包含招募研究參與者。

一旦邀請其他玩家完成任務，並記錄他們的：

- 語音。
- 遊玩畫面與帳號資訊。
- 問卷。
- 訪談。
- 行為事件。

就需要在收資料前確認知情同意、隱私與校內研究倫理要求。

## 同意項目要分開

參與者可以同意其中一項，不代表同意全部：

1. 參加遊玩測試。
2. 研究者錄製畫面與語音。
3. 資料用於論文分析。
4. 去識別片段用於口試播放。
5. 去識別片段用於研討會或網路公開。
6. 匿名處理資料公開在 Repository。

每個項目要能單獨勾選或拒絕。

## 參與者資料

公開研究資料只使用：

- 隊伍 ID，例如 `T001`。
- 參與者 ID，例如 `T001-P1`。
- 經驗與熟悉度的分組資料。

姓名、聯絡方式、帳號與匿名 ID 對照表放在私有資料區，與研究資料分開保存。

## 影片處理

口試或研討會影片要檢查：

- 遊戲暱稱。
- Steam／Discord 通知。
- 桌面與檔案路徑。
- 玩家聲音是否可能辨識。
- 聊天內容是否提到姓名或私人資訊。

處理方式可包括裁切、遮罩、改名、靜音、變聲或只保留字幕。採哪一種要依同意內容和研究需求決定。

## 撤回

正式招募前要決定並告知：

- 可在什麼時間點撤回。
- 撤回後哪些原始與處理資料會刪除。
- 資料已匿名彙整或公開後，哪些內容可能無法追回。
- 撤回的聯絡方式。

## 公開 Repository 的限制

不得提交：

- 未去識別原始影音。
- 同意書掃描。
- 參與者名單。
- 身分對照表。
- 私有雲端連結或可直接存取的路徑。
- 任何憑證或帳號資訊。

可以提交：

- 空白模板。
- 研究方法與編碼規則。
- 匿名彙整資料。
- 原始檔雜湊值與不暴露私有位置的代稱。
- 已取得公開同意的短片；但大型影片仍建議用外部保存與索引。

## 收資料前檢查

- [ ] 已查到校內最新正式要求。
- [ ] 已確認是否需要事前審查或核准。
- [ ] 招募文字沒有誇大好處或隱瞞錄製。
- [ ] 同意內容區分分析、口試與公開用途。
- [ ] 匿名 ID 規則已建立。
- [ ] 原始資料與身分對照分開保存。
- [ ] 撤回與刪除流程已寫清楚。
- [ ] 研究者知道誰可以存取資料。
- [ ] 影片公開前有第二次個資檢查。

## 尚待確認

- 校內研究倫理或受試者審查適用範圍。
- 正式同意書格式。
- 資料保存年限。
- 口試錄影是否視為公開使用。
- 研討會投稿與簡報中使用參與者語音的規定。
