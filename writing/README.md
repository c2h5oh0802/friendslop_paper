# 寫作工作區

寫作前先完成主張—證據對照，不從空白頁直接生成整章。

## 文件

- `chapter_plan.md`：前三章的工作結構與十月交付線。
- `claim_evidence_map.csv`：每個重要主張對應到來源、案例、實驗或影片。

正式章節草稿之後可放在：

```text
writing/chapters/ch01_introduction.md
writing/chapters/ch02_literature.md
writing/chapters/ch03_method.md
```

## 每段落最低要求

1. 這段要回答什麼。
2. 要提出哪個主張。
3. 主張由哪個來源或資料支持。
4. 證據不足時要降低語氣或標記待補。
5. 這段如何連回研究問題。

## 狀態標記

- `SUPPORTED`：已有足以支撐目前句子強度的證據。
- `PARTIAL`：有部分證據，但要降低主張或補資料。
- `HYPOTHESIS`：待實驗或案例分析。
- `UNKNOWN`：目前沒有可靠資料。
- `REJECTED`：已有證據否定或研究決定不採用。

沒有證據的句子不能因為寫起來順就保留。
